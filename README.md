# Como Executar

Clone o repositório:

```bash
git clone https://github.com/FlaviaVitoriadeQueiroz/Python.git
```

Entre na pasta:

```bash
cd Python
```

Instale as dependências necessárias:

```bash
pip install pandas numpy matplotlib scikit-learn
```

Execute os arquivos `.py` ou notebooks `.ipynb`.
